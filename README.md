## 🤖 How I use this repo with Claude

Each topic has its own tracker file. In a new chat I give Claude two links:
the `START_HERE.md` file and **only** the tracker I want to work on.

1. Claude reads `START_HERE.md` and the one tracker.
2. Claude finds the **Next up** line and resumes from there.
3. At the end, Claude gives me the full updated tracker file.
4. I save it and push it to this repo.

This way progress is never lost, even with the free plan or with many accounts.
